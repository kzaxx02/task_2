# depgraph — визуализатор графа зависимостей пакетов Python

## Общее описание

CLI-инструмент для анализа и визуализации графа зависимостей пакетов
Python (формат pip). Зависимости получаются без менеджеров пакетов и
сторонних библиотек. Используется только стандартная библиотека Python 3.

Проект разрабатывается поэтапно. Текущее состояние: **этап 1** —
минимальный прототип с конфигурацией через опции командной строки.
При запуске приложение проверяет параметры и выводит их в формате
«ключ: значение».

## Описание функций и настроек

### Опции командной строки

| Опция | Обязательна | Описание |
|-------|-------------|----------|
| `--package NAME` | да | Имя анализируемого пакета |
| `--repo REPO` | да | URL репозитория (http/https) или путь к файлу тестового репозитория |
| `--test-mode` | нет | Режим тестового репозитория: `--repo` — путь к файлу, имена пакетов — большие латинские буквы |
| `--version VER` | нет | Версия пакета, например `2.31.0` (по умолчанию `latest`) |
| `--ascii-tree` | нет | Вывод зависимостей в формате ASCII-дерева |
| `--filter SUBSTR` | нет | Не учитывать пакеты, в имени которых есть подстрока |

### Обработка ошибок

При неверном значении параметра программа печатает сообщение
`Ошибка: ...` в stderr и завершается с кодом 2. Проверяется:

- имя пакета: не пусто, допустимые символы; в тестовом режиме — только
  большие латинские буквы;
- репозиторий: корректный http(s) URL, а в тестовом режиме — существующий
  читаемый файл;
- версия: формат `1.2.3`, `2.0rc1`, `1.0.post1`, `1.0.dev1` или `latest`;
- подстрока фильтра: не пустая и без пробелов;
- отсутствие обязательных опций (сообщение argparse, код 2).

### Структура

```
src/depgraph/config.py  проверка параметров, класс Config
src/depgraph/cli.py     разбор командной строки, main()
tests/                  модульные тесты (unittest)
run.sh, Makefile        запуск и тесты
```

## Сборка и тесты

Сборка не требуется. Нужен Python 3.8+.

```
make test
```

или

```
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## Примеры использования

Обычный режим:

```
$ ./run.sh --package requests --repo https://pypi.org/ \
    --version 2.31.0 --ascii-tree --filter test
package: requests
repo: https://pypi.org/
test_mode: false
version: 2.31.0
ascii_tree: true
filter: test
```

Тестовый режим:

```
$ ./run.sh --package A --repo tests/data/test_repo.txt --test-mode
package: A
repo: tests/data/test_repo.txt
test_mode: true
version: latest
ascii_tree: false
filter:
```

Ошибки:

```
$ ./run.sh --package "bad name" --repo https://pypi.org/
Ошибка: недопустимое имя пакета 'bad name'
$ ./run.sh --package ab --repo tests/data/test_repo.txt --test-mode
Ошибка: имя тестового пакета 'ab' должно состоять только из больших латинских букв
$ ./run.sh --package requests --repo pypi.org
Ошибка: 'pypi.org' не является корректным URL (нужен http или https)
$ ./run.sh --package A --repo nofile.txt --test-mode
Ошибка: файл тестового репозитория 'nofile.txt' не найден
$ ./run.sh --package requests --repo https://pypi.org/ --version v1
Ошибка: недопустимая версия 'v1' (пример: 1.2.3)
$ ./run.sh --package requests --repo https://pypi.org/ --filter "a b"
Ошибка: подстрока фильтрации не должна содержать пробелы
```
